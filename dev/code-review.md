## 当前约束

- 数据库只初始化当前 DDL，不探测或修改旧表，不搬运旧数据。
- 不加入旧字段、旧协议、旧工具结果的兼容分支。
- 标准 Responses output 对象原样保存；工具结果由本项目构造标准 function_call_output，业务内容使用明确 JSON。
- SQL 直接写在 API 方法文件，不增加 repository/service 或查询封装。
- 图片文件独立存储，Base64 只出现在发给模型的请求中。
- Agent 使用传入的消息数组，循环没有轮数上限。
