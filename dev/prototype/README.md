# agentic 界面原型

本地 Agent 桌面客户端的高保真静态原型，纯 HTML / CSS / 原生 JS，无外部依赖（无 CDN、无外部字体、无外部图片）。

## 页面清单

| 文件            | 对应路由                 | 说明                                                                         |
| --------------- | ------------------------ | ---------------------------------------------------------------------------- |
| `index.html`    | —                        | 原型导航页，陈列所有页面入口与设计令牌速览                                   |
| `login.html`    | `/login`                 | 访问令牌登录                                                                 |
| `home.html`     | `/`                      | 新对话首页：侧栏 + 居中问候 + 输入框 + 2×2 起手卡                            |
| `chat.html`     | `/sessions/:id`          | 会话页：消息流、代码块、可折叠工具调用卡（含运行中态）、图片附件、usage 信息 |
| `browser.html`  | `/sessions/:id` + 浏览器 | 聊天 / 浏览器分栏：标签栏、地址栏、内嵌 SaaS 落地页 mock                     |
| `settings.html` | `/settings`              | 设置页：模型、外观、Mac 控制、浏览器、关于五组卡片表单                       |

## 如何预览

直接双击任意 HTML 文件，或在当前目录起本地服务：

```bash
cd dev/prototype
python3 -m http.server 8799
# 或 npx serve
```

然后访问 `http://localhost:8799/`。

## 设计令牌

- **主色**：靛蓝紫 `#5a5ff5`（hover `#6c70f8` / deep `#474de0`，soft 为 9% 透明度填充，聚焦外发光环 28% 透明度）；品牌渐变 `135deg #6c70f8 → #5a5ff5 → #7b5cf0`
- **中性色**：带冷蓝倾向；浅色主区 `#ffffff`、侧栏 `#f3f4f9`；深色底 `#0e0f14`（非纯黑），深色侧栏 `#111218`
- **语义色**：成功 `#17a05e`、警告 `#cf8408`、危险 `#e5484d`，均有对应 soft 底色
- **圆角**：卡片 12–16px、按钮 10px、输入框 16px、胶囊标签 999px
- **字号**：正文 15px / 1.75，侧栏 13.5px，辅助文字 12.5px，代码 13px（ui-monospace 栈）；字重 600 标题 / 500 强调 / 400 正文
- **阴影**：三层分层阴影 `--sh-sm / --sh-md / --sh-lg`（近处细描边 + 远处柔和投影），浮层另有 1px 半透明描边
- **布局**：侧栏 268px，对话内容列 max-width 768px 居中，浏览器分栏聊天侧 430px
- **主题**：`data-theme="light|dark"` 挂在 `<html>` 上，CSS 变量两套；右上角浮动小组件循环 浅色 → 深色 → 自动（跟随系统），选择存入 `localStorage`

## 交互（`assets/prototype.js`）

只做三件事：主题切换（含记忆与跟随系统）、工具调用卡点击折叠/展开、浏览器标签 active 切换（联动地址栏）。其余均为静态展示。图标全部为内联 SVG（stroke 1.5px、24 视窗，Lucide 风格），由 JS 注入 sprite。
